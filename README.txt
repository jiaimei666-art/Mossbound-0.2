MOSSBOUND - OVERRUN TERRAIN REWRITE UPDATE

Extract and open index.html to play. No installation or build is required.
Optional Google Fonts use the internet; the game also works with fallback fonts.

GITHUB: Replace index.html, game.js and style.css in the same folder of your
existing repository and commit the changes. These files contain the complete game.

NEW: Line of Code Overrun (X) excavates terrain with code rain and then rebuilds
it from below as permanent purple-and-black glitched blocks. They are solid and
can be mined for stone. Rebuilding waits for the player to leave a hole, and
protected arena floors, stations, Sky Lift and bottom layers remain protected.
The giant biome hand with terrain eruptions is included too.

Use the in-game Controls button for full controls. ADMIN33 in Codes unlocks Admin.
The current game stores avatar preferences, but not a full world/progression save.
